# docs

The Creative UI documentation site and registry host (Next.js 16, App Router).

- `pnpm dev` from the repository root starts it on http://localhost:3000 (the registry is built first).
- Component content lives in `src/content/components/<slug>/{meta.ts,live.tsx}`; one page template renders every component.
- The registry is served from `public/r` (generated by `scripts/build-registry.ts`; git-ignored).
- The `@/` alias resolves to `packages/ui/src`, so previews run the exact distributed files. Docs code uses `~/`.
- `AGENTS.md` is written by Next.js itself; keep it.
